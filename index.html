Flappy Bird

怎么玩

点击画面（或按 空格 / ↑）让小鸟向上飞。

松开就会自然下落，穿过上下管道的空隙 得 1 分。

撞到管道或掉到地面即结束，R 键重开。

小技巧

不要狂点，一下一下地点，让小鸟保持平稳的滑翔节奏。

眼睛盯着下一根管道的空隙中心，而不是盯着小鸟。

下落时提前轻点，比撞到了再补点更容易救回来。

关于

纯 HTML + CSS + JavaScript 手写，无任何依赖，手机电脑都能玩。

最高分会自动保存在本机浏览器里。

游戏设置

调整后立即生效，重新开局也会沿用当前设置。
