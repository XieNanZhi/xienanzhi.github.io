PERSONAL PROJECT · 已上线

Flappy Bird 网页游戏

复刻经典 Flappy Bird 的完整玩法：点击 / 空格控制小鸟飞行，穿越管道空隙得分， 内置难度递增、五套场景主题、可调参数设置与本地最高分记录。 从物理引擎到音效全部手写，单文件、零依赖，部署在 GitHub Pages 上。

  • 游戏循环：requestAnimationFrame + 帧时间步长（delta time），不同刷新率下手感一致
  • 物理系统：重力加速度、跳跃冲量、姿态角度插值，小鸟随速度抬头俯冲
  • 碰撞检测：AABB 包围盒算法，含容差收缩，避免“贴边判死”的挫败感
  • 渲染：Canvas 2D 分层绘制（天空 / 星月 / 云 / 海岛 / 管道 / 地面），devicePixelRatio 高清适配
  • 音效：WebAudio API 现场合成（振荡器 + 包络），不加载任何音频文件
  • 状态管理：ready / play / over 三态状态机，切后台自动暂停防跳帧
  • 数据持久化：localStorage 保存最高分与玩家设置，带解析容错

03

这个项目里的质量实践

写完只是开始，测过才算完成

以下是 Flappy Bird 项目开发中，我针对异常与边界场景做过的实际处理（均可对照源码验证）：

边界值控制 管道空隙随得分收窄但锁定下限 110px，保证极限难度仍可通过；小鸟触顶时位置钳制、速度归零。
异常输入防护 结束界面误触不直接重开（需命中按钮区域）；键盘 preventDefault 阻止空格滚动页面。
生命周期处理 切换标签页 / 最小化时通过 visibilitychange 重置时间戳，避免回来时一帧跳变直接“坠机”。
多端兼容验证 鼠标、触屏（touch-action + 被动事件）、键盘三路输入统一收口；devicePixelRatio 适配高分屏不模糊。
数据容错 localStorage 读取全部包裹 try/catch 并校验取值范围，旧数据损坏时回退默认配置。
性能意识 单文件零请求、无图片资源（全程序化绘制）、帧循环内零对象分配，低端手机也流畅。
