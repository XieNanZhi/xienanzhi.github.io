# xienanzhi.github.io

小鸟快飞吧 —— Flappy Bird 奶油海风版。

在线玩：https://xienanzhi.github.io

## 玩法

- 点击画面 / 空格 / 向上键：小鸟向上飞
- 松手自然下落，穿过上下管道的空隙得 1 分
- 撞到管道或落地即结束，按 R 重开
- 最高分自动保存在浏览器本地

## 技术

单文件 `index.html`，原生 Canvas 2D + JavaScript，无依赖、无构建步骤。
支持鼠标、触屏、键盘三种操作，高清屏自适应。

## 更新

修改 `index.html` 提交后，等 1~5 分钟网站自动更新。
